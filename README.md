# Rift Runner (Basic)
Guide the Cloak of Levitation through scrolling dimensional barriers.

Basic features only:
- B1 Gravitational Pull: constant gravity; any key / click thrusts up; ground or ceiling ends the run.
- B2 Endless Rifts: barrier pairs scroll in from the right at regular intervals with a random gap height; touching one ends the run.
- B3 Cycle of Rebirth: +1 point per gap passed; final score shown at game over; one key press / click restarts.

Run: `npm install && npm start` (or open `src/index.html` in a browser). Test: `npm test`.
